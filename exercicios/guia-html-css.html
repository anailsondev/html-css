Guia dos seus exercícios: HTML e CSS

HTML cria o conteúdo e a estrutura; CSS muda a aparência e a posição.

Como ler o código

<p class="destaque">Um parágrafo</p>  <!-- HTML: elemento/tag -->

p.destaque { text-align: center; }    /* CSS: seletor + propriedade + valor */

Tag é algo como <p> ou <table>. text-align não é tag: é uma propriedade CSS. center, left, right e justify são valores dela.
