Manual de consulta: HTML e CSS

Conceitos práticos dos exercícios e desafios deste projeto. Cada tópico traz finalidade, sintaxe, componentes relacionados e exemplo em contexto.

1. HTML

HTML organiza o conteúdo e informa o significado das partes de uma página. Elementos são escritos com tags; atributos acrescentam configurações à tag de abertura.

1.1 Documento e metadados

DOCTYPE, html, head, meta, title, link e style

Para que serve:

DOCTYPE seleciona o modo HTML moderno. html é a raiz do documento. head contém metadados e recursos; meta configura informações; title nomeia a aba; link conecta arquivos; style contém CSS interno.

Sintaxe/Atalho:

<!DOCTYPE html>
<html lang="pt-BR"><head>...</head><body>...</body></html>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • lang define idioma, como pt-BR.
  • meta charset="UTF-8" configura caracteres acentuados.
  • meta name="viewport" content="width=device-width, initial-scale=1.0" adapta a janela à tela.
  • meta name="description" content="..." descreve a página.
  • link rel="stylesheet" href="style.css": rel indica folha CSS e href seu caminho.

Exemplo Prático Combinado:

<!DOCTYPE html>
<html lang="pt-BR"><head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meu site</title><link rel="stylesheet" href="style.css">
</head><body>Conteúdo</body></html>

1.2 Estrutura semântica

body, header, nav, main, section, article, aside, footer, div e span

Para que serve:

Elementos semânticos nomeiam o papel das regiões. div e span são agrupadores sem significado próprio: bloco e trecho em linha, respectivamente.

Sintaxe/Atalho:

<header>...</header><main><section>...</section></main>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • body: conteúdo da página; header: cabeçalho da página/seção.
  • nav: navegação; aria-label pode nomeá-la.
  • main: conteúdo principal, em geral único.
  • section: grupo temático, geralmente com título.
  • article: unidade que pode ser compreendida sozinha.
  • aside: informação complementar; footer: rodapé.
  • div/span: agrupam quando não há elemento semântico apropriado; class é reutilizável e id identifica algo único.

Exemplo Prático Combinado:

<body><header><h1>Site</h1></header>
<nav aria-label="Principal"><a href="#noticia">Notícia</a></nav>
<main><article id="noticia"><h2>Título</h2><p>Texto</p></article><aside>Relacionado</aside></main>
<footer>Contato</footer></body>

1.3 Títulos, texto e listas

h1–h6, p, ênfase e tags textuais

Para que serve:

Títulos organizam hierarquia e p forma parágrafos. Tags textuais comunicam ênfase, relevância, citação, código ou outra função semântica.

Sintaxe/Atalho:

<h1>Tema principal</h1><h2>Subtema</h2><p>Parágrafo.</p>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • h1 é título principal; h2–h6 níveis de seção; siga hierarquia, não tamanho visual.
  • strong importância; em ênfase; b/i/u convenções de destaque, termo ou anotação.
  • mark realce contextual; small observação; del/ins removido/inserido.
  • sub/sup subscrito/sobrescrito; abbr title abreviação e explicação.
  • code trecho de código; pre preserva espaços e quebras.
  • q/blockquote citação curta/em bloco; br quebra pertinente; hr mudança temática; bdo dir controla direção do texto.

Exemplo Prático Combinado:

<article><h1>HTML</h1><p><strong>Importante:</strong> veja <code>alt</code>.
<abbr title="HyperText Markup Language">HTML</abbr> estrutura páginas.</p>
<blockquote>Uma citação em bloco.</blockquote></article>

ul, ol, li, dl, dt, dd

Para que serve:

Organizam itens: lista sem ordem, lista ordenada ou pares de termo e descrição.

Sintaxe/Atalho:

<ul><li>Item</li></ul>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • ul: itens sem sequência; ol: sequência; li: item filho.
  • ol start define início, reversed inverte contagem e type seleciona marcador.
  • dl agrupa descrições, dt é termo e dd definição.

Exemplo Prático Combinado:

<ol><li>Planejar</li><li>Construir</li></ol>
<dl><dt>CSS</dt><dd>Estilo da página</dd></dl>

1.4 Links, imagens e mídia

a

Para que serve:

Cria link para página, arquivo, endereço externo ou parte identificada da página.

Sintaxe/Atalho:

<a href="pagina.html">Abrir página</a>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • href destino; #id aponta para âncora.
  • target="_blank" abre nova aba; use rel="noopener".
  • rel descreve relação; texto do link deve explicar destino.

Exemplo Prático Combinado:

<a href="#contato">Ir ao contato</a><section id="contato">...</section>

img, picture, source, figure, figcaption

Para que serve:

Exibem imagem, alternativas responsivas e legenda associada.

Sintaxe/Atalho:

<img src="foto.jpg" alt="Descrição">

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • src caminho; alt descrição acessível (vazio se decorativa); width/height dimensões.
  • picture contém opções source com srcset, media ou type, e um img padrão.
  • figure agrupa conteúdo visual e figcaption fornece legenda.

Exemplo Prático Combinado:

<figure><picture><source media="(min-width:800px)" srcset="grande.jpg">
<img src="foto.jpg" alt="Montanhas ao amanhecer"></picture>
<figcaption>Paisagem</figcaption></figure>

audio, video, source e iframe

Para que serve:

Incorporam áudio, vídeo ou outro documento (iframe).

Sintaxe/Atalho:

<audio controls><source src="som.mp3" type="audio/mpeg"></audio>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • controls mostra controles; autoplay, muted, loop alteram reprodução; poster define capa do vídeo.
  • source src/type informa arquivo e formato alternativo.
  • iframe src aponta conteúdo incorporado; title descreve finalidade.

Exemplo Prático Combinado:

<video controls><source src="filme.mp4" type="video/mp4">Vídeo indisponível</video>
<iframe src="mapa.html" title="Mapa da cidade"></iframe>

1.5 Tabelas

table, grupos, linhas e células

Para que serve:

Apresenta dados relacionados em linhas e colunas; não deve ser usada para construir o layout geral.

Sintaxe/Atalho:

<table>...</table>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • caption legenda; thead/tbody/tfoot cabeçalho/corpo/rodapé.
  • tr linha; th cabeçalho; td dado.
  • scope="col|row|colgroup|rowgroup" relaciona cabeçalho; colspan/rowspan mesclam colunas/linhas.
  • colgroup/col identificam colunas.

Exemplo Prático Combinado:

<table><caption>Notas</caption><thead><tr><th scope="col">Aluno</th><th>Nota</th></tr></thead>
<tbody><tr><th scope="row">Ana</th><td>9,5</td></tr></tbody></table>

1.6 Formulários

form e controles

Para que serve:

Coleta e envia dados. HTML oferece validação no navegador; processamento/salvamento exige serviço ou código no servidor.

Sintaxe/Atalho:

<form action="/cadastro" method="post">...</form>

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • action destino; method método (get ou post).
  • label for associa rótulo ao input id; name é chave enviada.
  • input type: text, email, password, number, date, radio, checkbox, file, submit.
  • value valor; placeholder dica (não substitui rótulo); required obrigatório.
  • min/max, minlength/maxlength, pattern limitam valores.
  • Radio de mesmo name forma escolha única; checkbox permite múltiplas escolhas.
  • select/option seleção; textarea texto longo; button type pode ser submit, reset ou button.
  • fieldset/legend agrupam controles e nomeiam grupo.

Exemplo Prático Combinado:

<form action="/contato" method="post"><fieldset><legend>Contato</legend>
<label for="email">E-mail</label><input id="email" name="email" type="email" required>
<button type="submit">Enviar</button></fieldset></form>

2. CSS

CSS define apresentação e layout. Uma regra tem seletor e declarações; cada declaração associa uma propriedade a um valor. Cascata, especificidade e ordem resolvem conflitos.

2.1 Seletores, estados e regras

Regra CSS e seletores

Para que serve:

Selecionam elementos do HTML para aplicar estilos.

Sintaxe/Atalho:

seletor { propriedade: valor; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • p tipo; * todos; .classe grupo reutilizável; #id identificador único.
  • A B descendente; A > B filho direto.
  • :hover, :active, :visited, :focus estados de interação/link/foco.
  • ::before/::after pseudoelementos, geralmente exigem content.
  • /* comentário */; @import importa CSS; @font-face registra uma fonte.

Exemplo Prático Combinado:

.menu a:hover { color: navy; }
.botao:focus { outline: 2px solid orange; }
.item::before { content: "› "; }

2.2 Cor e tipografia

color, text-align, text-indent, text-decoration, text-shadow e line-height

Para que serve:

Controlam cor, alinhamento, recuo, decoração, sombra e espaçamento de linhas de texto.

Sintaxe/Atalho:

p { color: #203040; text-align: justify; line-height: 1.6; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • color: cor por nome, hexadecimal, rgb(a) ou hsl(a).
  • text-align: left, right, center, justify.
  • text-indent: recuo da primeira linha.
  • text-decoration: none, underline, overline, line-through.
  • text-shadow: deslocamento x/y, desfoque opcional e cor.
  • line-height: distância vertical entre linhas.

Exemplo Prático Combinado:

.intro { color: #203040; text-align: justify; text-indent: 2em; line-height: 1.6; }
a { text-decoration: none; } a:hover { text-decoration: underline; }

font-family, font-size, font-weight, font-style e font

Para que serve:

Escolhem família, tamanho, espessura e inclinação da fonte; font é atalho que reúne configurações.

Sintaxe/Atalho:

body { font-family: Arial, sans-serif; font-size: 1rem; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • font-family lista fontes e termina em genérica serif/sans-serif/monospace.
  • font-size tamanho; font-weight normal, bold ou 100–900; font-style normal/italic.
  • @font-face associa font-family, src, font-weight, font-style; link/import pode buscar fontes externas.
  • font atalho: tamanho e família necessários; estilo/peso e altura de linha opcionais.

Exemplo Prático Combinado:

@font-face { font-family: Minha; src: url("fonte.woff2"); }
body { font: 400 1rem/1.6 Minha, Arial, sans-serif; }

2.3 Caixa, medidas e bordas

box-sizing, width, height e limites

Para que serve:

Definem cálculo e dimensões da caixa. border-box inclui padding e borda dentro da dimensão declarada.

Sintaxe/Atalho:

* { box-sizing: border-box; } .caixa { width: 300px; height: auto; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • content-box dimensiona só conteúdo; border-box inclui conteúdo, padding e borda.
  • width/height largura/altura; min/max-width/height estabelecem limites.

Exemplo Prático Combinado:

* { box-sizing: border-box; } main { width: 90%; max-width: 1000px; margin: auto; }

margin e padding

Para que serve:

Margin é espaço externo; padding é espaço interno entre conteúdo e borda.

Sintaxe/Atalho:

.card { margin: 1rem auto; padding: 1rem 1.5rem; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • Variantes -top, -right, -bottom, -left controlam lados.
  • Atalho: 1 valor todos; 2 vertical/horizontal; 3 topo/horizontal/baixo; 4 topo/direita/baixo/esquerda.
  • margin:auto centraliza bloco com largura definida; padding não aceita negativo.

Exemplo Prático Combinado:

.card { max-width: 600px; margin: 1rem auto; padding: 12px 20px; }

border, border-radius, outline, box-shadow

Para que serve:

Desenham bordas, arredondam cantos, destacam foco e aplicam sombras.

Sintaxe/Atalho:

.card { border: 1px solid #ccc; border-radius: 8px; box-shadow: 0 2px 8px #0002; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • border atalho largura/estilo/cor; versões: border-width/style/color e lados. Estilos: solid, dashed, dotted, double, none.
  • border-radius raio dos cantos.
  • outline contorno que não ocupa espaço; width/style/color. Preserve indicação visível de foco.
  • box-shadow deslocamento x/y, blur, espalhamento e cor; inset cria sombra interna.
  • border-image-source/slice/repeat selecionam imagem, recorte e repetição da borda; atalho border-image.

Exemplo Prático Combinado:

.button { border: 2px solid navy; border-radius: 6px; box-shadow: 0 2px 4px #0003; }
.button:focus { outline: 3px solid orange; }

2.4 Fundos

background e subpropriedades

Para que serve:

Define cor ou imagem de fundo e como ela aparece na caixa.

Sintaxe/Atalho:

.banner { background: #123b5d url("fundo.jpg") center / cover no-repeat; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • background-color: cor; background-image: url() ou linear-gradient().
  • background-repeat: repeat, no-repeat, repeat-x, repeat-y.
  • background-position: posição como center ou left top.
  • background-size: cover cobre (pode cortar), contain mostra imagem toda; aceita dimensões.
  • background-attachment: scroll acompanha rolagem; fixed prende à janela.
  • background é atalho que reúne camadas e configurações.

Exemplo Prático Combinado:

.banner { background-color: #123b5d; background-image: linear-gradient(90deg, navy, teal); background-position: center; background-size: cover; background-repeat: no-repeat; }

2.5 Exibição e layout

display e Flexbox

Para que serve:

Display decide participação no fluxo e modelo de layout. Flexbox organiza filhos em uma dimensão.

Sintaxe/Atalho:

.menu { display: flex; gap: 1rem; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • block bloco; inline flui no texto; inline-block flui e aceita dimensões; none oculta/remova espaço.
  • flex e grid ativam layout flexível/grade.
  • Flex: flex-direction eixo; justify-content distribuição no eixo principal; align-items eixo cruzado; flex-wrap quebra de linha; gap intervalo.
  • Itens: flex-grow, flex-shrink, flex-basis regulam crescimento, redução e base.

Exemplo Prático Combinado:

.nav { display: flex; flex-wrap: wrap; justify-content: center; align-items: center; gap: 1rem; }

position, offsets, z-index, transform e overflow

Para que serve:

Position define referência e participação no fluxo; transform altera aparência/posição visual; overflow controla conteúdo excedente.

Sintaxe/Atalho:

.pai { position: relative; } .filho { position: absolute; top: 0; right: 0; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • static padrão; relative mantém espaço e cria referência; absolute sai do fluxo em relação ao ancestral posicionado.
  • fixed ancora na janela; sticky pode prender durante rolagem.
  • top/right/bottom/left deslocam; z-index ordena camadas.
  • transform: translate, rotate, scale; não reorganiza fluxo.
  • overflow/-x/-y: visible, hidden, auto (rolagem quando precisa), scroll.

Exemplo Prático Combinado:

.pai { position: relative; }
.filho { position: absolute; top: 1rem; right: 1rem; z-index: 1; }
.lista-larga { overflow-x: auto; }

2.6 Tabelas, media queries e unidades

border-collapse, border-spacing, vertical-align

Para que serve:

Controlam aparência das células e alinhamento vertical.

Sintaxe/Atalho:

table { border-collapse: collapse; }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • border-collapse: collapse|separate une ou separa bordas.
  • border-spacing define distância em modo separate.
  • vertical-align: top/middle/bottom em células ou elementos inline.
  • text-align alinha horizontalmente.

Exemplo Prático Combinado:

table { width: 100%; border-collapse: collapse; }
th, td { border: 1px solid #aaa; padding: 8px; vertical-align: top; }

@media

Para que serve:

Aplica CSS condicional conforme mídia, tamanho ou orientação, adaptando a página a telas e impressão.

Sintaxe/Atalho:

@media screen and (min-width: 700px) { main { max-width: 1000px; } }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • screen/print: tela/impressão.
  • min-width/max-width: limites de largura; and combina condições.
  • orientation: portrait|landscape: orientação vertical/horizontal.
  • vw/vh: percentuais da janela; min(), max(), clamp() limitam medidas fluidas.
  • Imagens fluidas: max-width:100%; height:auto.

Exemplo Prático Combinado:

img { max-width: 100%; height: auto; }
@media screen and (min-width: 700px) { main { width: 90%; margin: auto; } }
@media print { nav { display: none; } }

Unidades, valores e funções CSS

Para que serve:

Unidades medem tamanho/posição; funções compõem valores dinâmicos ou recursos.

Sintaxe/Atalho:

.caixa { width: 80%; padding: 1rem; transform: translateX(0); }

Subpropriedades, Tags Filhas ou Atributos Relacionados:

  • px pixel CSS; % relativo ao contexto; em relativo à fonte do elemento; rem à fonte raiz.
  • vw/vh relativo à largura/altura da janela.
  • auto cálculo automático; inherit herda; initial valor inicial; none ausência de efeito quando permitido.
  • url() recurso; linear-gradient() gradiente; translate() deslocamento.
  • @charset "UTF-8"; declara codificação no início da folha CSS, quando necessário.

Exemplo Prático Combinado:

@charset "UTF-8";
:root { font-size: 16px; }
.caixa { width: min(90vw, 60rem); padding: 1em; }

Como consultar: localize o elemento ou propriedade; leia sua finalidade e componentes; depois adapte o exemplo ao seu conteúdo.
